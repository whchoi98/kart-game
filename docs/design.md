# TURBO PALS GRAND PRIX — 게임 디자인 문서

터보 팰즈 그랑프리는 브라우저에서 바로 즐기는 아케이드 3D 카트 레이싱 게임입니다.
장르적 재미(드리프트 미니 터보, 아이템 역전, 8인 그랑프리)는 카트 레이싱의 고전 공식을
따르되, 캐릭터·아이템·트랙·그래픽·음악은 모두 새로 만든 오리지널입니다.

## 1. 핵심 루프

1. 모드와 배기량(50/100/150/200cc)을 고르고, 8명의 드라이버 중 한 명을 선택합니다.
2. 트랙 소개 플라이오버 → 3·2·1 카운트다운(타이밍 맞춰 가속하면 로켓 스타트) → 3랩 레이스.
3. 드리프트로 코너를 돌며 미니 터보를 모으고, 아이템 박스로 역전 수단을 얻습니다.
4. 결과 화면 → 그랑프리 포인트 누적 → 4개 트랙 종료 후 시상대와 트로피.

## 2. 조작

| 동작 | 키보드(1인) | 게임패드 | 터치 |
| --- | --- | --- | --- |
| 조향 | ←/→ 또는 A/D | 왼쪽 스틱 / D-패드 | 왼쪽 조향 패드 |
| 가속 / 브레이크·후진 | ↑·W / ↓·S | A / B | 가속 / 브레이크 버튼 |
| 점프·드리프트 | Space 또는 Shift | RB / RT | 드리프트 버튼 |
| 아이템 | E, Z, Ctrl | LB / LT | 아이템 버튼 |
| 뒤보기·뒤로 던지기 | Q 또는 C | X / Y | 뒤보기 버튼 |
| 일시정지 | Esc, P | Start | 화면 상단 버튼 |

2인 대전은 P1이 WASD + 왼쪽 Shift/E/Q, P2가 방향키 + 오른쪽 Shift/Enter/오른쪽 Ctrl을 씁니다.

## 3. 주행 물리 (결정론적 60 Hz)

- **가속/최고속**: 배기량별 기준 속도(50cc 21 m/s … 200cc 34 m/s)에 캐릭터 능력치를 곱합니다.
- **조향**: 속도가 붙을수록 조향 권한이 커지고, 최고속에서는 70%로 줄어 안정적입니다.
- **드리프트**: 점프 버튼을 누른 채 조향하면 드리프트. 호 반경은 조향 방향에 따라
  넓게 52 m / 중립 25 m / 타이트 12.5 m이며, 드리프트 시간에 따라 파랑(0.75초)·주황(1.55초)·
  보라(2.6초) 스파크가 충전되고 떼는 순간 0.55/1.05/1.6초 미니 터보가 발동합니다.
- **점프와 트릭**: 램프 끝에서 공중으로 뜨면 점프 버튼으로 트릭 → 착지 시 0.7초 부스트.
- **노면**: 오프로드(속도 55%), 진흙(42%), 빙판(접지력 급감). 부스트 중에는 오프로드 무시.
- **벽/카트 충돌**: 충격량에 비례한 감속과 반발, 무게(질량) 차이에 따른 밀어내기.
- **코인**: 최대 10개, 개당 최고 속도 +0.5%. 피격 시 1~3개를 잃습니다.
- **로켓 스타트**: 카운트다운 "2" 이후 적절한 순간(tick 128~152) 가속 → 1.25초 부스트,
  너무 일찍 누르고 있으면 엔진 과열로 0.9초 출발 지연.

## 5. 아이템 (순위 가중 확률)

바나나(×3), 통통 구슬(×3, 벽 반사), 추적 로켓(×3), 니트로(×3), 슈퍼 스타(무적·가속),
번개 구름(상대 축소), 먹물 문어(앞선 레이서 시야 가림), 터보 로켓(자동 질주),
선두 폭탄(1위 폭격), 코인 주머니. 하위권일수록 강한 아이템이 나오며, 번개는 16초 쿨다운,
선두 폭탄은 동시에 하나만 존재합니다. 단일 바나나·구슬·로켓은 버튼을 누르고 있으면 뒤에
매달아 방패로 쓰고, ×3 아이템은 주위를 돌며 공격을 막습니다.

## 6. 트랙과 컵

| 컵 | 트랙 | 테마 | 특징 |
| --- | --- | --- | --- |
| 새싹 컵 | 햇살 초원 서킷 | 초원 | 입문 코스, 양 떼 시케인, 언덕 트릭 램프 |
| 새싹 컵 | 야자수 해변 | 해변 | 난간 없는 부두 구간, 게, 모래 언덕 점프 |
| 새싹 컵 | 붉은 협곡 랠리 | 협곡 | 굴러오는 바위, 협곡 점프, 비포장 지름길 |
| 새싹 컵 | 네온 시티 나이트 | 도시 | 8자 고가도로, 차량 통행 |
| 번개 컵 | 눈꽃 봉우리 | 설산 | 빙판 코너, 눈덩이, 스키 점프 |
| 번개 컵 | 정글 유적 | 정글 | 흔들다리, 진흙, 통나무 |
| 번개 컵 | 용암 요새 | 화산 | 용암 다리, 나선 오르막, 해자 점프 |
| 번개 컵 | 별빛 은하 로드 | 우주 | 난간 없는 무지개 도로, 운석 |

미러 모드는 트랙을 좌우 반전합니다. 150cc 골드 트로피로 200cc, 두 컵 모두 150cc
골드로 미러 모드가 열립니다.

## 7. 모드

- **그랑프리**: 4개 트랙, 순위 포인트 15-12-10-8-6-4-2-1. 첫 레이스는 맨 뒤 출발,
  이후 레이스는 누적 순위의 역순 그리드.
- **VS 레이스**: 트랙·배기량·CPU 수(0~7)·아이템 유무 자유 설정.
- **타임 어택**: 니트로 3개로 시작. 내 최고 기록 고스트 또는 세계 1위 고스트와 경쟁.
  입력 로그를 서버가 **재시뮬레이션해 틱 단위로 검증**한 기록만 순위에 오릅니다.
- **2인 대전**: 상하 분할 화면, 키보드 두 세트 또는 게임패드 두 개.

## 8. CPU 드라이버

레이싱 라인(코너 안쪽 정점) 추종, 곡률 기반 드리프트 제어(코너 곡률에 맞춰 드리프트 강도를
역산), 위험물·무버 회피, 아이템 전술(방패 유지, 정렬 시 발사, 직선에서 니트로),
로켓 스타트 확률, 난이도별 속도·노이즈, 완만한 러버밴딩(선두 인간과의 거리 기반 ±10%).

## 9. 결정론과 공정성

`src/sim`은 DOM·three.js·`Math.random`·`Date`·`Math.sin`을 쓰지 않습니다. ECMAScript는
삼각함수 결과를 엔진마다 다르게 허용하므로, 사칙연산과 `Math.sqrt`만으로 만든
`dsin/dcos/datan2/dexp`를 씁니다. 모든 사람 입력은 16비트 워드로 양자화된 뒤 시뮬레이션에
들어가므로, 라이브 주행과 입력 로그 재생 결과가 비트 단위로 같습니다.
